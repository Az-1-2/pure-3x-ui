# Журнал синхронизаций с upstream

Автоматически ведётся workflow `Sync Upstream`. Обновляется при каждом
sync, если upstream выпустил новый релиз (изменился `internal/config/version`).

Статусы:

- ⏸️ — код подтянут в `main`, ждём тестирования.
- 🧪 — тестируется на отдельном VPS.
- ✅ — протестировано, выпущен релиз форка.
- ❌ — отклонено (проблемы, ждём фикса в upstream).
